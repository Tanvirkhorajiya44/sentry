# Senetry

A full-stack inventory and business management system built with React, Node.js, and MySQL.

## Features
- Password-only login
- Dashboard with modules:
  - Inventory (Add/Dispatch Product)
  - Godown (Manage Locations)
  - Customers/Suppliers
  - Expenses & Cash Book
  - Reports & Analytics

## Setup

### Backend
1. `cd backend`
2. `npm install`
3. Configure MySQL in `config/db.js`
4. `npm start`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev` (for development)
4. `npm run build` (to build for production)
5. `npm run preview` (to preview production build)
